Tile Shuffle Image Solver (Browser)

回転なし・欠損なしのタイルシャッフル画像を、境界の勾配一致（MGC）＋ビームサーチ＋局所探索で復元します。
計算は Web Worker 上で行うため、実行中も画面は固まりません。5×5 以上でも通常は既定値のままで動きます。

2) パラメータ / Parameters



詳細設定 / Advanced

目安: 7×7 までは既定値（beam 1200 / cand 40）のままで可。誤りが残る場合のみ beam を 3000〜5000 に。
境界がきれいな画像は wm/hm を 0 に。band は raw スコア時のみ有効。

3) 実行 / Run


手動修正: 復元画像のタイルを 2枚順にクリック すると入れ替えます。
