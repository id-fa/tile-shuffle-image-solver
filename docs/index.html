Tile Shuffle Image Solver (Web)

A browser-based tool to reconstruct grid-tiled images whose tiles were shuffled (no rotation), using gradient-based edge compatibility (MGC) + beam search + local refinement. / タイル分割された画像（回転なし）のシャッフルを、境界の勾配整合性（MGC）＋ビームサーチ＋局所探索で復元するブラウザアプリです。

日本語

概要

本Webアプリは、画像を rows×cols のグリッドとして扱い、タイルの順序だけが入れ替わった画像を 境界の勾配整合性（MGC）に基づいて推定し、ビームサーチ＋局所探索で自動復元します（タイル回転は扱いません）。 計算は Web Worker 上で行うため、実行中も画面は固まりません。

主な機能

  • 画像読み込み（PNG/JPEG）
  • パラメータ設定（rows/cols/wm/hm/beam/cand ほか。詳細設定に score/orders/refine/band/step）
  • MGC スコア＋ビームサーチ＋局所探索による自動配置（完全シャッフル想定、最大 64 タイル）
  • 手動修正：タイルを2枚順にクリックで入れ替え（swap）
  • 行・列の循環シフト（ループスクロール）で上下左右のズレを一発補正
  • Preview Zoom（スライダー）で出力プレビューを拡大縮小
  • 復元画像をPNG保存
  • mapping.txt のエクスポート／インポート

クイックスタート

  1. Image からシャッフル画像を読み込む
  2. 必要に応じて rows/cols と wm/hm を設定
  3. Auto Solve を実行
  4. 崩れている場合：
    • 行/列の循環シフト（↑↓←→ボタン）で全体ズレを補正
    • 残りはタイルを2枚クリックして入れ替え
  5. Save PNG で保存（必要なら mapping.txt も保存）

パラメータの目安

パラメータ推奨範囲説明
rows/cols2〜77×7 まで既定値で数秒以内。最大 64 タイル
Max Size800〜1200長辺を縮小して計算（速度/安定性に効きます）
beam1200（既定）7×7 まで既定値で十分。誤りが残る場合のみ 3000〜5000 に
cand40（既定）各状態で試す候補タイル数
orders4（既定）走査順の数。1 にすると約 4 倍速いが局所解に落ちやすい
refineon（既定）探索後の局所探索（巡回シフト・2タイル交換）
scoremgc（既定）raw は旧来の画素差分（互換用）
band/step3 / 1band は raw スコア時のみ有効。step は境界サンプリング間隔
wm/hm0〜10セル内トリム（境界ノイズ対策）。境界がきれいな画像は 0 が最良
復元できないとき
まず wm/hm を 0 にして再実行し、それでも崩れる場合は beam を上げてください。 星空や単色の空のように一様な領域内のタイル同士は境界情報では区別できないため、2タイルクリックで手動修正してください。

制限事項

  • タイルの回転（90°/180°）は非対応
  • タイル欠損がある画像は非対応
  • ほぼ一様な領域（星空・単色の空など）内では、タイル同士が入れ替わることがあります

English

Overview

This web app reconstructs grid-tiled images whose tiles have been shuffled in order (no rotation), using gradient-based edge compatibility (MGC), beam search and local refinement. The solver runs in a Web Worker, so the page stays responsive.

Key Features

  • Load PNG/JPEG images
  • Adjust parameters (rows/cols/wm/hm/beam/cand; score/orders/refine/band/step under Advanced)
  • Automatic placement via MGC scoring + beam search + local refinement (fully shuffled tiles, up to 64)
  • Manual fix: click two tiles to swap
  • Row/column cyclic shift (loop scroll) to quickly fix global offsets
  • Preview Zoom slider (output preview scaling)
  • Save reconstructed image as PNG
  • Export/Import mapping.txt

Quick Start

  1. Load a shuffled image via Image
  2. Set rows/cols and optionally wm/hm
  3. Run Auto Solve
  4. If the result is close but offset:
    • Use row/column cyclic shift buttons (↑↓←→)
    • Use two-click swaps for remaining mistakes
  5. Save via Save PNG (optionally export mapping)

Practical Parameter Ranges

ParameterRecommended RangeNotes
rows/cols2–7Up to 7×7 solves in seconds with defaults. Max 64 tiles
Max Size800–1200Downscale longest side to improve speed/stability
beam1200 (default)Enough up to 7×7; raise to 3000–5000 only if mistakes remain
cand40 (default)Candidate tiles expanded per state
orders4 (default)Traversal orders. 1 is ~4x faster but more prone to local minima
refineon (default)Local refinement after the search (cyclic shifts, pairwise swaps)
scoremgc (default)raw is the legacy L1 pixel difference
band/step3 / 1band applies to the raw score only; step is the seam sampling interval
wm/hm0–10Inner trimming for boundary noise. Use 0 for clean boundaries
If the result is wrong
Retry with wm/hm = 0 first, then raise beam. Tiles inside a uniform region (starry sky, flat colour) cannot be told apart from boundary information; fix them with two-click swaps.

Limitations

  • Tile rotation (90°/180°) is not supported
  • Missing tiles are not supported
  • Tiles inside near-uniform regions (starry sky, flat colour) may be swapped with each other

操作メモ / Interaction Notes

  • Manual swap：出力プレビューのタイルを click 2回（2枚）で入れ替え / Click two tiles to swap.
  • Row/Col shift：行・列を循環シフトして上下左右のズレを補正 / Cyclic shift fixes global offsets quickly.
  • Zoom：Zoomスライダーで出力プレビューの見やすさを調整 / Use zoom slider for comfortable editing.
  • mapping.txt：復元結果を保存し、同条件で再利用可能 / Export and reuse reconstruction mapping.
